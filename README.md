# The Void

A simple single page site, where you stare into the dark depths of the Void. It is eerily empty and claustrophobically cold. You may click anywhere in the Void ... if you dare. The Void itself is a strange place. It is lonely, dark and yet somehow soothing. Some say the Void itself may be alive stares back at you if you happen to gaze into the darkness for too long.
